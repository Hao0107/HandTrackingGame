# README
Rolling Sky fangame engine made with Unity3D

## Features
Core Mechanics: Faithful recreation of Rolling Sky gameplay (ball movement, physics, and tile-based levels).
Hand Tracking Integration: Powered by MediaPipe, allowing players to control the ball by moving their hands in front of a webcam.
Real-time Response: Low-latency mapping between hand coordinates and in-game ball position.
Unity-Based: Built with Unity3D for easy cross-platform builds and customization.

## Installation
Clone the repository git clone https://github.com/Hao0107/HandTrackingGame.git
Open in Unity: Launch Unity Hub and add the cloned folder.
